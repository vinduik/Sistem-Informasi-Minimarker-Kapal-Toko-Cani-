# 🏪 TOKO CANI
### Sistem Informasi Manajemen Toko & Point of Sale (POS) (Mini Market Kapal)

**Toko Cani** adalah aplikasi berbasis web yang dirancang untuk membantu pengelolaan operasional toko secara terintegrasi, mulai dari transaksi penjualan, pembelian barang, pengelolaan stok persediaan, hingga penyusunan laporan usaha.

Aplikasi ini dikembangkan menggunakan **PHP Native dan MySQL/MariaDB**, dengan antarmuka yang dirancang agar mudah digunakan dalam aktivitas operasional toko sehari-hari.

## ✨ Fitur Utama

- **Manajemen Produk** — Mengelola data barang, kategori, harga jual, harga beli, dan satuan produk.
- **Transaksi Penjualan (POS)** — Memproses transaksi penjualan dengan keranjang belanja dan perhitungan otomatis.
- **Transaksi Pembelian** — Mencatat pembelian barang dari pemasok.
- **Manajemen Persediaan** — Memantau stok barang dan perubahan persediaan.
- **Barcode Scanner** — Mendukung pencarian dan pemindaian barang menggunakan barcode.
- **Konversi Satuan** — Mendukung pengelolaan barang dengan berbagai satuan dan konversinya.
- **Manajemen Pemasok** — Mengelola informasi supplier atau pemasok.
- **Metode Pembayaran** — Mendukung pencatatan berbagai metode pembayaran.
- **Penjualan Tunai dan Kredit** — Mendukung transaksi pembayaran langsung maupun utang.
- **Laporan Penjualan** — Menyediakan informasi transaksi penjualan.
- **Laporan Pembelian** — Menyediakan informasi transaksi pembelian.

## 🛠️ Teknologi

- PHP Native
- MySQL / MariaDB
- HTML5
- CSS3
- JavaScript
- Bootstrap (jika digunakan pada antarmuka)

## 🎯 Tujuan Pengembangan

Toko Cani dikembangkan untuk membantu pelaku usaha toko dalam meningkatkan efisiensi operasional, meminimalkan kesalahan pencatatan manual, mempermudah pengawasan persediaan, serta menyediakan informasi transaksi yang lebih terstruktur.

## 🚀 Pengembangan Selanjutnya

Aplikasi ini dapat terus dikembangkan sesuai kebutuhan operasional, seperti penyempurnaan laporan, pengelolaan piutang dan utang, serta pengembangan fitur manajemen toko lainnya.
